# ☕ CafeStock: Optimización de Inventario para Hostelería

## ⚠️ El Problema
Como profesional con 15 años de experiencia en hostelería, he visto cómo se pierde dinero a diario por procesos ineficientes. La gestión de stock en muchas cafeterías sigue dependiendo de "bolígrafo y papel", cálculos mentales rápidos y una dependencia extrema de la memoria de un par de personas clave. Esto genera tres problemas críticos:

*   **Ineficiencia Operativa:** El proceso de compra depende de individuos específicos y no de un sistema.
*   **Ceguera Financiera:** El control de mermas y consumos es inexistente; no sabemos cuánto se pierde ni qué productos están lastrando nuestra rentabilidad.
*   **Escalabilidad nula:** Un proceso que debería ser automático se convierte en un cuello de botella.

## 🚀 La Solución
**CafeStock** es el primer paso hacia la automatización real del punto de venta. A diferencia de un Excel estático, esta herramienta está diseñada para:

1.  **Automatizar la reposición:** Centralizar los niveles de stock para que cualquier miembro del equipo pueda realizar la gestión.
2.  **Visibilidad de datos:** Generar reportes gráficos sobre ventas y consumos para identificar patrones.
3.  **Enfoque de Negocio:** Diseñado bajo una lógica de "cocina", priorizando cuándo se vende y cuánto se gasta.
